## What is CleanMac?

CleanMac finds and removes cache files, build artifacts, and temporary clutter from your Mac. It handles 35+ cache types from browsers, developer tools, chat apps, and system folders — all from the menu bar.

## Features

- **Safe Clean** — daily refresh of auto-regenerating caches
- **Deep Clean** — thorough cleanup with destructive-target confirmation
- **Menu Bar** — background monitoring with low-space notifications
- **Keyboard shortcuts** — ⌘S / ⌘D
- **100% offline** — no telemetry, no accounts

## Requirements

- Apple Silicon (M1/M2/M3/M4)
- macOS 12 Monterey or later

## Installation

1. Download the latest DMG from [Releases](https://github.com/totnormal/CleanMac-Releases/releases)
2. Drag to Applications
3. First launch: Right-click → Open
